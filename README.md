# Word to PDF Converter

A simple and free online tool to convert Word documents into PDF files.

## Features

- Convert DOC files to PDF
- Convert DOCX files to PDF
- Simple and user-friendly interface
- No registration required
- Free to use
- Responsive design

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- LibreOffice
- Docker

### Deployment
- Frontend: Render
- Backend: Render
- Source Code: GitHub

## How It Works

1. Open the website.
2. Select a DOC or DOCX Word document.
3. Click **Convert to PDF**.
4. The document is processed by the backend.
5. The converted PDF is returned to the user.
